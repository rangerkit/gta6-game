# Palm Vice

An original open-world crime game built for the make.fun "Make GTA 6" bounty — a sun-soaked coastal city you can explore on foot and by car, with traffic, pedestrians, stealable cars, a wanted level with police response, missions and a story, combat, a HUD with minimap, a start screen and saves. All names, characters, art and story are our own. Plays fully offline in a desktop browser from the static files in `game/`.
